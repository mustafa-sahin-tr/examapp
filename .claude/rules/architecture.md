- **exam-dotnet-api**: ana backend (api/) + Angular frontend (ui/)
- **Services/Gateway**: Ocelot API Gateway, tüm istekler buradan geçer
- **Services/OutboxPublisher**: outbox mesajlarını RabbitMQ'ya publish eder
- **Services/BadgeService**: outbox mesajlarını consume eder — İSİM YANILTICI, sadece badge değil TÜM outbox event'lerini handle eder (örn: soru çözüldüğünde puan hesaplama)
- **auth-api + auth-ui**: Keycloak entegrasyonu; auth-ui Angular, Keycloak login akışını yönetir
- **Python servisi**: YOLO tabanlı — yaprak test/soru bankası görsellerinden soru ve şık sınırlarını tespit edip crop eder
- **Soru sınıflandırma**: öğretmen soru oluşturunca `QuestionCreatedEvent` → BadgeService `QuestionCreatedConsumer` → `IQuestionClassifier` soru görselini LLM'e verip ders/konu/alt konu/zorluğu belirler ve exam API'ye geri yazar (`ClassificationSource=AI`). Sağlayıcı `QuestionAnalyzer:Provider` ile seçilir: `Claude` (varsayılan, `ClaudeQuestionClassifier`, #469 — taksonomiyi exam API `GET /api/questions/classifier-taxonomy`'den alır, prompt caching ile önbellekler, taksonomi dışı id'yi reddeder) veya `Gemini` (`GeminiQuestionClassifier`). (Eskiden n8n yapıyordu; kaldırıldı.) **Kitap içindekileri (#577):** işaretleme ekranından kitap sayfası kaydedilince ders/konu/alt konu içindekilerden gelir, `ClassificationSource=Book`; `QuestionCreatedEvent.SubTopicIds` taşır. Davranış `QuestionAnalyzer:BookTocMode` ile: `Hybrid` (varsayılan, boşken de) — alt konu varsa sınıflandırma yok, yalnız konu varsa sınıflandırıcı taksonomiyi o konuya daraltır (`classifier-taxonomy?topicId=`), yalnız alt konu + zorluk yazılır, konu/ders ve kaynak `Book` kalır, konu da yoksa normal sınıflandırma; `Skip` — kitap soruları hiç sınıflandırılmaz; `Always` — Human gibi (AI sonucu kitabın konusunun üzerine yazar). Geçersiz değer açılışta patlar. Gemini konuya daraltamaz: Hybrid'de konu-sınırlı sınıflandırmayı atlar (kitabın konusu kalır). **Görselsiz soru (#590):** görseli olmayan soru (görsel 404) Claude'da metinle sınıflandırılır (`GET /api/questions/{id}/classification-text`: kapsam, yönerge, kök, şıklar, plan etiketleri; çözüm yok); Gemini atlar. **Öğretmen kilidi (#590):** toplu kayıtta soru başına `classification.locked` + konu → `QuestionCreatedEvent.TaxonomyLocked`; alt konu varsa sınıflandırma yok, yalnız konu varsa o konu içinde (kaynak `Human` kalır).
- **İstisna — exam API consumer'ları**: `StudentPointsChangedEvent` (#225) ve `StudentBadgeEarnedEvent` (#422) BadgeService yerine exam API'de tüketilir (`StudentPointsChangedConsumer` → `StudentPoints` + günlük puan defteri `StudentDailyXps`; `StudentBadgeEarnedConsumer` → `StudentBadgeProjections`, veli paneli rozetleri); yazılan tablolar exam DB'de ve servisler arası HTTP/DB paylaşımı yasak. Kural: event'in yazdığı veri hangi serviste ise consumer orada olur; diğer tüm outbox event'leri BadgeService'e eklenir. BadgeService'in kendi outbox'ı `badge-outbox-publisher` ile yayınlanır.
